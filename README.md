## About Me

Data Science student with hands-on experience building end-to-end ML pipelines — from raw EDA to deployed applications. I focus on projects that produce defensible, measurable results, not just notebooks that run once.

- 🔭 Currently working on: **RAG-based document intelligence** and **automated EDA tooling**
- 🎓 Data Science Intern @ Venom Technologies — built ML classifier achieving **87.3% accuracy** on 5K-row movie dataset
- 💡 Interested in: ML systems, LLM applications, data pipelines
- 📍 Mumbai, India
